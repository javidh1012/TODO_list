# SmartTask Voice - TODO List App

SmartTask Voice is a simple TODO List web application built to help users manage daily tasks with ease.  
It offers a clean interface and voice-based interaction for a better user experience.

## Features
- Add tasks
- Voice command support
- Clear all tasks
- Simple and clean UI
- Easy to use

## Technologies Used
- HTML
- CSS
- JavaScript

## Voice Commands
- **Add Task**
- **Clear All**

## How to Use
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start adding and managing your tasks.
